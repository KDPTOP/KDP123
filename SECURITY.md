# Security

kdp123 is a static website with no accounts, no database and no user input stored on the server.

If you find a security problem (for example a way to inject content into a page, or a leaked secret in the repository
history), please report it privately through GitHub's "Report a vulnerability" button on the repository's Security tab
instead of opening a public issue.

Please do not run automated scans against kdp123.com that generate significant load.
